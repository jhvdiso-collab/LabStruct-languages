# Лабораторная работа №1: абстрактные структуры данных

Вариант 2 — **АВЛ-дерево**. C++17 реализует массив, односвязный и двусвязный
списки, стек, очередь и АВЛ. В Go независимо реализованы пять линейных структур.
Контейнеры хранят знаковые 32-битные целые числа. Динамическая память, связи узлов,
расширение массива и балансировка реализованы вручную. Стандартные map/vector/slice
используются также для реестра имён, разбора команд и сериализации, но не заменяют
реализацию самих изучаемых структур.

## Сборка и проверки

Ветка `cpp` содержит реализацию на C++17. Реализация Go находится в ветке `go`.

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build --parallel 2
ctest --test-dir build --output-on-failure
```

Все проверки этой ветки: `bash scripts/check.sh`.

## Запуск

Примеры ниже описывают обе реализации; исполняемый файл другой реализации собирается из соответствующей ветки.

Один запуск — одна команда. Каждый запуск загружает файл, выполняет запрос,
сохраняет изменения и завершается.

## Массив — M

| Команда | Действие |
|---|---|
| `MPUSH name value` | Добавить в конец |
| `MINSERT name index value` | Вставить по индексу; разрешён индекс, равный длине |
| `MGET name index` | Получить значение |
| `MDEL name index` | Удалить по индексу |
| `MSET name index value` | Заменить значение |
| `MLEN name` | Получить длину |
| `PRINT name` | Прочитать все элементы |

## Списки — F и L

Ниже `X` нужно заменить на `F` (односвязный) или `L` (двусвязный).
Индекс в операциях **BEFORE/AFTER обозначает существующий опорный элемент**.
Например, для `[10 20 30]` команда `FDELAFTER name 0` удаляет `20`.

| Команда | Действие |
|---|---|
| `XPUSH name value`, `XPUSHBACK name value` | Вставка в хвост |
| `XPUSHFRONT name value` | Вставка в голову |
| `XPUSHBEFORE name index value` | Вставка до опорного элемента |
| `XPUSHAFTER name index value` | Вставка после опорного элемента |
| `XDELFRONT name` | Удаление головы |
| `XDELBACK name` | Удаление хвоста |
| `XDELBEFORE name index` | Удаление перед опорным элементом |
| `XDELAFTER name index` | Удаление после опорного элемента |
| `XDEL name index` | Удаление по индексу |
| `XDELVAL name value` | Удалить первое совпадение; вернуть `TRUE`/`FALSE` |
| `XFIND name value` | Индекс первого совпадения; `-1`, если нет |
| `XGET name index` | Чтение по индексу |
| `XLEN name` | Длина |
| `XREVERSE name` | Прочитать в обратном порядке, **не изменяя** список |
| `PRINT name` | Прочитать в прямом порядке |

## Стек — S, очередь — Q

| Команда | Действие |
|---|---|
| `SPUSH name value`, `QPUSH name value` | Добавить значение |
| `SPOP name`, `QPOP name` | Прочитать и удалить по LIFO/FIFO |
| `SGET name`, `QGET name` | Прочитать следующее значение без удаления |
| `PRINT name` | Прочитать всё без удаления |

## АВЛ — T (только C++)

| Команда | Действие |
|---|---|
| `TINSERT name value` | Вставить с балансировкой; `TRUE`, если новый ключ |
| `TGET name value`, `ISMEMBER name value` | Проверить наличие, `TRUE`/`FALSE` |
| `TDEL name value` | Удалить с балансировкой; `TRUE`, если ключ был |
| `PRINT name` | Симметричный обход |
